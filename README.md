# OnlineShop

OnlineShop to projekt REST API sklepu internetowego stworzony w **C# (.NET 8)** z użyciem **Entity Framework Core** oraz **JWT**.  
System umożliwia rejestrację i logowanie użytkowników, zarządzanie produktami, koszykiem, listą życzeń oraz zamówieniami.  
Obsługiwane role to **Customer**, **Admin** oraz **SalesDepartmentWorker**, co pozwala na różne poziomy dostępu i funkcjonalności.  

API jest udokumentowane przy pomocy **Swagger UI** i może być łatwo zintegrowane z aplikacją webową lub mobilną.  
Dane przechowywane są w bazie **SQL Server**, a architektura systemu została oparta na ASP.NET Core Web API.  
Projekt powstał jako część realizacji zadania akademickiego i stanowi przykład implementacji nowoczesnych aplikacji e-commerce w technologii .NET.
